# 0.18.0 交互改进

## 本轮范围

1. 发现页：浏览内容向下滚动时收起搜索栏和快捷入口，反向滚动唤出。入口为分类、排行榜、最近更新、每周连载、周刊推荐；统一等宽横向排列，超出范围时边缘渐隐，可横滑查看。
2. 详情页：开始阅读、下载、收藏统一一行，扣除页边距和按钮间距后按 2∶1∶1 分配宽度。已有阅读进度继续恢复；从头阅读、购买和下载权限判断保留。
3. 收藏：打开本地／云端双选面板；登录后默认云端，未登录默认本地。切换选项不触发写入，确认加入或取消才操作；未登录选择云端时引导登录。
4. 阅读：移除在线／离线来源和模式提示条、沉浸悬浮按钮、三点菜单及其图片导出入口。中央矩形占内容面积 50%，点击可切换阅读菜单；四周点击不切换，滑动和缩放保持。标题字号缩小，设置位于最右侧，增加返回首页按钮。
5. 返回路径：从继续阅读进入后，返回箭头和系统返回均跳至该作品详情；换章后仍保持此路径。首页按钮清除阅读导航栈并选择发现页。
6. 我的：头像居左，账号标识优先显示用户名、缺失时显示 UID；长名称自动缩小。移除已登录提示，四个账号入口统一为等宽、同高的图标文字按钮。

上一轮目录工具栏与折叠搜索同时纳入本版，见 [交互说明](DETAIL_TOOLBAR.md)。
