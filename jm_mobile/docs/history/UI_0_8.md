# 0.8.0 · Material 3 界面改进

日期：2026-10-18。用户已验收 0.7.0；该版本的 APK 和源码快照保留。本次改进覆盖全套前端布局及登录入口。

## 设计依据

- [Material 3 基础](https://m3.material.io/foundations/)：以颜色角色、字体层级、组件形状和布局间距统一界面。
- [Material 3 适配布局](https://m3.material.io/foundations/layout/canonical-examples/overview)：手机/中等/展开窗口的布局。
- [Flutter Material 3 迁移说明](https://docs.flutter.dev/release/breaking-changes/material-3-migration)：使用当前 SDK 支持的 SearchBar、SegmentedButton、DropdownMenu、MenuAnchor 等组件。

沿用本机 Flutter 3.44.8 的 Material 库；不为本次视觉改造升级运行时或引入新的 UI 框架。

## 全局设计

`lib/ui/design_system.dart` 集中维护配色及组件主题：使用 ColorScheme 语义颜色，surface 容器区分内容层级；统一应用栏、卡片、搜索栏、表单、按钮、弹窗、底部面板、导航栏与导航轨道。

- 以 8/16/24 的间距组织页面，卡片圆角 12，弹窗/底部面板圆角 28，表单保留 Material 文本框形状。
- 按钮及图标操作保持至少 48 的触控空间，组件继续提供焦点、语义、禁用和交互状态。
- 紧凑窗口使用底部导航，宽度 600 起使用 NavigationRail；内容区域限制最大宽度，详情/表单等页面使用更窄的阅读宽度。
- 使用 Material 3 颜色角色生成浅/深主题；阅读器保留黑色图像画布，操作区域采用独立深色 Material 主题。
- 保留现有主题色、字体族/粗斜体/缩放、封面大小和标题行数。列表按实际列宽计算高度，封面固定 3:4 比例。

## 登录入口的产品调整

- 保留账号密码登录。
- 辅助操作仅保留“注册账号”，通过 Android 系统浏览器打开原项目的注册页 `https://comic18j-jjeg.cc/signup`。
- 删除应用内 AccountWebScreen 页面；登录页不再出现应用内注册、密码找回、重发验证或邮箱验证入口。
- 浏览器打开失败时显示原站地址。没有自动执行注册、打开浏览器或提交真实账号操作。
