## 构建环境

Flutter 3.44.8 / Dart 3.12.2；Android SDK 36、JDK 21、AGP 8.13.2、Kotlin 2.2.21、Gradle 8.14.5。

原协议移植核对 `jmcomic==2.6.20` wheel 的原始实现，SHA256 见 MIGRATION.md。保留上游 LGPL/MIT/GPL 许可与翻译来源。

Google Maven 直连超时，使用可选 `JM_USE_MAVEN_MIRROR=true` 获取过构建依赖；最终通过缓存离线构建 `:app:assembleDebug`。默认不启用镜像。Kotlin 跨盘增量缓存异常用 `kotlin.incremental=false` 规避。

单包参数：`-Ptarget-platform=android-arm64 -PjmAbi=arm64-v8a -Pdisable-abi-filtering=true`，避免混入其他 ABI 的插件二进制。
