# 0.8.0 前端产品评审

评审日期：2026-10-19。依据：当前源码、0.8.0 的 13 张组件渲染图及既有功能说明。渲染图使用合成内容；本次未进行安卓设备交互走查，性能和手势问题另列为待验证项。

总体判断：核心功能已经成形，界面组件有统一基础；产品组织仍明显围绕功能清单展开。最需要改进的是阅读连续性、书库概念、状态反馈、信息密度与异常恢复。

评审中的“问题”包括源码可确认的交互行为，以及基于现有界面的产品判断，并不表示每项都是程序错误。P1 优先处理核心任务中断、进度错位或误操作；P2 改善理解和操作效率；P3 结合使用反馈安排。

沿用既定范围：注册通过原网站完成；应用内密码找回和邮箱验证按用户要求移除；超分、NAS、网络增强和检查更新的既定排期保持不变。

## 一、核心路径与信息架构

| 编号 | 优先级 | 问题与影响 | 改进方向 |
|---|---|---|---|
| 01 | P1 | 首页没有最近阅读/继续阅读入口，回访用户需要经过历史或重新寻找漫画。 | 首页提供最近阅读卡，直接显示章节与页码。 |
| 02 | P1 | 详情页“开始阅读”固定打开第一章，只恢复该章页码；读到其他章节的用户不能从主按钮继续。 | 有进度时以“继续阅读”作为主操作，另保留从头阅读。 |
| 03 | P1 | 底部栏目通过替换子页面切换，列表位置、来源选择与临时筛选缺少稳定保留。 | 切换栏目保留各页状态，明确何时主动刷新。 |
| 04 | P1 | 详情阅读入口没有统一优先解析已下载章节；同一本内容从历史/下载和从详情进入会走不同路径。 | 统一章节打开策略，优先可用的离线文件并标明来源。 |
| 05 | P1 | 本地收藏、本地历史、本地书库分散在不同栏目。“本地”分别意味着书签、进度和图片文件，容易混淆。 | 统一书架的内容视图，分别呈现收藏、最近阅读和离线状态。 |
| 06 | P1 | 收藏默认进入云端，未登录也先出现登录引导；已有本地收藏的新用户需要再次切换。 | 默认尊重登录状态、已有本地内容或上次来源。 |
| 07 | P1 | 登录状态主要依据本地令牌是否存在；认证过期没有统一的重新登录流程。 | 认证失效时明确原因，保留当前任务并提供登录后返回。 |
| 08 | P2 | 账号资料、签到、我的评论藏在“设置”的下一层，账号与偏好设置的职责混合。 | 以“我的”整合账号任务，偏好设置作为其中的次级入口。 |

依据：`app.dart` 的页面切换和 loggedIn；`detail_reader.dart` 的主阅读按钮；`bookcase.dart` 的默认来源；`discovery.dart` 的章节打开分支。

## 二、首页、发现与搜索

| 编号 | 优先级 | 问题与影响 | 改进方向 |
|---|---|---|---|
| 09 | P2 | 手机首屏被搜索、五个入口和分组标题占用较多空间，示例界面约只能完整浏览两本推荐。 | 根据真实内容调整首屏密度，减少固定头部占用。 |
| 10 | P2 | 分类、排行榜、连载、周刊并排，入口有了，但缺少对用户选择目标的帮助。 | 按“找内容/看排行/追更新”组织入口，适度说明数据口径。 |

| 12 | P2 | 封面失败时只有缺图图标，用户难以判断是内容无封面还是加载失败。 | 设计明确占位、失败提示和可恢复的重试行为。 |

## 五、下载、离线与批量操作

| 编号 | 优先级 | 问题与影响 | 改进方向 |

| 38 | P2 | 未设置导出目录时主要用提示让用户自己返回设置寻找，流程被打断。 | 从导出动作直接进入目录选择，授权后继续原任务。 |

## 待设备确认的风险

以下不是已复现缺陷：

- 展开全部搜索筛选并弹出软键盘后，窄屏或大字下是否挤压或溢出。
- 连续阅读、双指缩放、横向翻页之间的手势是否相互抢占。
- 刘海、系统手势区、横屏和分屏窗口下工具栏是否遮挡。
- TalkBack 焦点顺序、独立操作名称、超大系统字体是否真正可用。
- 大量章节、真实封面、长图、低内存与慢网时的滚动及加载体验。
- 前后台切换、系统回收、目录授权失效和导出部分失败时的用户恢复路径。

## 建议顺序

1. 先恢复核心连续性：继续阅读、正确章节/页内位置、栏目状态保留、统一离线入口、认证失效引导。
2. 再统一书库与管理：解释本地/云端/离线关系，修正批量选择范围和下载反馈，直接完成导出。
3. 再改善发现与详情：筛选摘要、结果语义、首屏密度、章节定位、付费内容访问状态。
4. 然后优化沉浸阅读、互动编辑器、状态规范与无障碍；平板分栏按使用反馈安排。

可验证的产品验收目标：切换栏目后不丢当前位置；详情主按钮能回到最近阅读章节；同一漫画从不同入口获得一致的离线行为；任何删除操作的实际数量与确认数量一致；下载提示与队列实际结果一致；系统大字设置不会被应用静默覆盖。
