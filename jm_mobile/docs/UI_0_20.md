# 0.20.0 详情页与缓存

## 设计

- 作品标题放在封面上方，清晰封面放大至内容宽度约 43%（上限 240dp），右侧仅显示作者与 JM 号，不重复显示总章节数。目录标题仍显示章节数量。
- 返回栏与详情共用一层封面背景，消除分别裁切造成的横向分界。背景按页面宽度适配、顶部对齐，不再按整页高度裁切或额外缩放；高斯模糊 sigma 18，叠加表面色与渐变，衔接下方页面。深浅主题均跟随当前表面色。
- 背景限制解码宽度至 192px，并使用 ImageFiltered 与 RepaintBoundary；不对滚动内容执行 BackdropFilter。页签滚动后仍固定在返回栏下方，详情／评论及原操作栏保持。
- 删除“从头阅读”。普通章节不再出现“未下载”；已下载章节在标题后显示有纯色底纹的圆形对勾，列表及紧凑短框都支持，保留“已下载”的可访问性名称。排队、下载中、暂停、失败及阅读页码仍可显示。

## 详情缓存

客户端进程内缓存最多 40 部作品，5 分钟有效，按最近使用淘汰；重复进入立即显示缓存数据，同一作品并发请求合并。异常不缓存，过期后重新请求。

缓存按账号令牌和 API 配置隔离，切换账号／连接配置不复用旧数据。收藏、购买成功会使对应缓存失效；购买前的价格复核与显式重试强制请求最新数据。评论和下载状态仍独立加载，不被详情缓存冻结。

这是有界的内存缓存，关闭应用进程后重新进入仍需加载，不新增作品元数据磁盘存储。
