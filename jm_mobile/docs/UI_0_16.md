# kamico 0.16.0

2026-10-19，以已验收的 0.15.0 为基础。名称改为 kamico，图标为白底粉色 K；应用包名 `app.jmpic.jm_mobile` 和开发签名保持兼容。历史版本产物保留。

## 详情与目录

- 两个页签：详情、评论。简介、作者与标签、目录放到详情中。
- 简介超过四行时展示摘要，点击展开后可选取全文；标签超过六项可展开。
- 目录默认显示六章，紧凑样式默认十二章；点击展开全部，按需构建。支持收起、搜索、倒序和定位最近章节。
- 目录旁的样式按钮沿用首页“图标按钮 → 底部面板 → 当前选项勾选”的交互；详细列表和紧凑短框可快速切换，选择持久化。紧凑列数随宽度与字体缩放调整。

## PDF 下载

- 每章一个 PDF，默认保存到系统 `Downloads/kamico/作品名称_编号/章节名称_编号.pdf`。部分系统文件管理器将系统下载目录显示为 `Download` 或“下载”。
- 图片按阅读顺序、等物理宽度、原比例排入无边距 PDF 页；目录设置 `OneColumn` 连续竖向布局。外部阅读器仍可用其自身设置覆盖默认布局。
- 移除 PNG 选项；旧任务中的格式字段不再影响生成结果。导入图片也生成 PDF，手动另存同样输出 PDF。
- 图片逐张处理并流式写入，避免将整本解码图一次性装入内存。失败 PDF 不发布为完整离线章节，重试可复用已完成图片；损坏图片不会覆盖旧 PDF。
- Android 10 起经 MediaStore.Downloads 发布，先写待发布文件再对外显示；Android 7–9 使用限定公共下载子目录并在需要时申请存储权限，拒绝后任务失败，避免自动重复弹权限请求。
- 应用内继续保留断点及离线缓存。删除本地库缓存和卸载不会删除公共 PDF。旧版完成的图片不在升级时批量转换，可选中“导出选中”另存为 PDF。
- 自动重试失败、暂停、前台下载等行为沿用原队列；后台下载服务未加入。

存储实现依据 [Android 共享存储文档](https://developer.android.com/training/data-storage/shared/media)。

## 阅读与外观

- 阅读仅提供三种模式：竖向连续滑动（新安装默认）、向右滑动、向左滑动；工具栏显示当前模式和方向图标，点按可进入设置。设置给出手势方向说明。
- 旧单页、双页及水平连续模式按手势方向迁移为单页翻页；旧竖向与适宽模式迁移为竖向连续。阅读进度、缩放、自动阅读和离线阅读保留。
- 外观字体默认跟随系统，移除固定三个字体族菜单，改为可搜索的设备字体列表；只在选中时读取并加载字体，重启会恢复选择。原通用字体设置迁回跟随系统。
- Android 10 起通过 [SystemFonts.getAvailableFonts](https://developer.android.com/reference/android/graphics/fonts/SystemFonts#getAvailableFonts()) 读取，较旧系统枚举可读取的标准字体目录。列表只包含系统开放的字体文件，不能访问其他应用私有字体；部分厂商字体可能不可见。字型集合采用文件默认字型，名称使用实际字体文件名。不可用字体回退系统字体。
- 评论日期移到卡片右上角，浅灰色小字；评论正文为 17sp、1.55 行高，回复按钮移到正文下方。跟随系统及应用字号缩放。
