# 详情目录工具栏设计

更新日期：2026-10-19。最初通过 0.17.0 Debug 热重载验证，现已纳入 [0.18.0 正式版](UI_0_18.md)，安装后重启仍保留。

## 设计方向

保持默认页面简洁，把次要内容按需展开。沿用 Material 3、响应式布局和现有简介/目录折叠行为。

- 左侧依次为章节数量、搜索入口、正序/倒序；目录样式独立靠最右侧。左侧在窄屏或大字体下允许换行，右侧保留触摸区域。
- 目录样式使用标准 IconButton，默认无填色，保留正常按压反馈。选项和样式持久化沿用原实现。
- 搜索默认收起，点击后用 200ms 尺寸动画向下展开。使用与首页相同的 SearchBar 组件及全局主题，包括圆角、底色、搜索图标和间距。
- 输入即筛选，清空按钮仅在有查询时出现。再次点击搜索入口收起时清除筛选并关闭键盘，避免隐藏筛选条件。
- 定位最近章节会同步显示搜索框和筛选文本；排序、目录展开和按需构建保留。

## 验证

- `flutter analyze --no-pub`：无问题。

- 小米 22041211AC、Android 14、1080×2400，手机网络全程使用用户配置的 VPN；自动点击进入详情、展开搜索、打开样式面板并切换紧凑模式，通过真机截图检查。
