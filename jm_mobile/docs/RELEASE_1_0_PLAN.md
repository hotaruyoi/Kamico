# kamico 1.0 改进计划

日期：2026-10-20。用户已确认 0.23.0 真机验收通过，作为本轮基线。本计划已获授权并实施，正式版 **1.0 / 1.0.0+27** 的实际交付及检查见 [RELEASE_1_0.md](RELEASE_1_0.md)。下文保留确认的范围与设计依据。

## 正式版界面与关于信息

- 用户界面、安装名称和发布说明采用正式产品表述，清理开发阶段、迁移阶段的介绍和占位文案。
- 设置中的版本页聚焦应用名称、版本及运行日志入口，移除“Flutter 独立客户端 · Android 优先”等技术介绍，以及尚未接入的更新说明。
- 设置常规页面去除 Qt 项目介绍。开源许可按实际使用情况保留：Flutter/Dart 运行依赖、移植的协议/翻译/图像处理实现及其必要署名、版权和许可正文。
- 当前 `LICENSE` 与 `third_party/picacg.LICENSE` 内容一致，合并重复许可展示，关联对应来源；保留 LGPL 正文、其引用的 GPL 正文和实际采用的 MIT 声明。必要来源署名放在对应许可详情中，常规设置页不展示迁移介绍。
- 原包名、签名及递增 versionCode 延续，支持从 0.23.0 覆盖升级。内部构建身份和数据隔离沿用现行规则；原参考工程和来源资料继续存档。

## 1. 详情封面右侧元数据

- JM 显示作者、JM 编号、点赞三个信息块；Pic 显示作者、点赞两个信息块，隐藏 Pic 编号，也不保留空行。
- 信息块间距由当前 16dp 提高到 24dp，块内多行作者保持正常行距。作者缺失时其余信息自然向上衔接，适配长作者名、窄屏与大字体。
- 点赞行改为“图标 + 数字”，移除“点赞”文字，数字使用粗体；仍为只读信息。
- 接口缺失值显示图标和“—”，无障碍语义说明暂无数值；真实 0 显示加粗 0。JM / Pic 上游字段映射不改。

完成标准：Pic 不出现编号占位；信息间距清楚且无溢出；点赞不再重复显示文字，0 和缺失仍可区分。

## 2. 书架与历史选择交互、底部操作条

- 两页顶部按钮始终保留，文案固定为“选择”。首次点击进入选择状态，再次点击退出、收起操作条并清空勾选；启用态用填充/颜色表达。
- 长按条目仍可进入选择状态，底部“完成选择”作为就近退出入口，与顶部按钮调用同一退出逻辑。
- 覆盖书架本地/云端和本地历史现有选择能力，保留各源允许的全选、移动、移除、删除和撤销操作。
- 将共用操作条作为透明外围的浮动圆角层呈现，排查并去除外围矩形底色、遮罩或多余阴影。只有圆角条本身着色，条外可见列表；菜单不能拦截外围列表的点击/滚动。
- 列表尾部按操作条实际高度与安全区增加可滚动余量，大字体时菜单可换行，最后一条仍能完整滚到条上方。

已确认：书架用 `if (!_selecting)` 移除了开启后的按钮；历史保留按钮但改变文案。外围方框的具体绘制层仍需在实施时复现定位，不能仅凭当前未展开菜单的截图认定根因。

完成标准：两页顶部按钮位置/文案不跳变，连续点击可开关；圆角操作条外围没有深色矩形；勾选和数据操作保持准确，末项可完整查看。

## 3. 发现页入口拖动排序

- 在“设置 → 外观与语言”增加“发现页入口排序”，进入独立排序页。
- 展示五个带图标的填充式列表项：分类、排行榜、最近更新、每周连载、周刊推荐。每项右侧提供清楚的拖拽手柄，拖动时突出当前项和插入位置。
- 提示“上方项目显示在发现页左侧”；拖放后立即保存，提供“恢复默认”。为无障碍操作提供上移/下移语义。
- 采用一套全局顺序，两源共用。连载、周刊标注“仅 JM”，Pic 自动略过这两项，其余三项保持同一相对顺序。
- 保留发现页现有横向滚动及尺寸，不涉及搜索栏、卡片密度、数据源切换按钮的位置，也不新增隐藏入口功能。
- 将入口定义为稳定标识，图标、名称、来源能力和目标路由绑定为同一项，按标识重排。当前路由依赖数组下标，不能仅移动文案数组，否则可能打开错误页面。
- 存入现有公共外观偏好；没有该设置时沿用旧顺序，重复/未知标识过滤，缺少的入口按默认顺序补齐。返回发现页立即生效，重启后保留。

完成标准：拖放后的显示顺序、图标和实际目标页面一致；两源切换和重启后顺序稳定；恢复默认有效，排序不改变账号、搜索或收藏数据。

## 4. 阅读菜单呼出时保持画面稳定

- 当前顶部 AppBar 随菜单出现/消失，底部控制栏也插入/移出漫画所在的 Column，导致漫画区域高度变化；同时 `_toggleChrome` 切换系统栏，安全区变化也需一并处理。
- 阅读内容采用稳定的全屏布局；顶部导航、底部进度/自动阅读控制和章节提示改为覆盖层，显隐只作用于覆盖层的透明度/位置，不参与漫画尺寸计算。
- 控件自身避让系统状态栏和导航区域；系统栏显隐不通过内容层 SafeArea 改变漫画坐标。设备旋转或真实窗口尺寸变化仍正常重排。
- 显隐菜单时保持图片元素、分页/滚动控制器、缩放状态、当前页和页内进度；不执行补偿跳页或重置图片来掩盖抖动。
- 菜单隐藏后移除其点击命中，显示时按钮可操作；图片中央区域仍控制呼出/收起，原翻页、缩放和连续阅读手势保持。

完成标准：同一阅读位置下呼出/收起菜单，漫画位置、尺寸、滚动偏移和页码保持一致；覆盖竖向连续、左右翻页、横竖屏、长图、离线阅读和末章提示场景。

## 实施顺序与交付边界

1. 优先处理阅读菜单位移和选择条交互/绘制，固定内容区域与手势行为。
2. 完成详情排版和拖动排序，再统一正式版关于信息、许可展示与语言词典。
3. 检查深浅主题、窄屏/大字体、系统栏显隐、拖动后路由和旧数据覆盖升级，使用合成内容验证数据修改行为。
4. 形成 1.0.0+27 同版本双包，沿用签名与身份隔离；设备可用时按现行规则安装，记录实际状态。

主要落点：`lib/ui/reader.dart`、`bookcase.dart`、`library_layout.dart`、`detail_reader.dart`、`preferences.dart`、`discovery.dart`、`settings.dart`、`lib/main.dart` 和语言词典。入口定义独立为小型领域模块并复用现有偏好存储，不增加依赖。

本轮不扩展数据源 API、账号能力、后台下载、发布仓库或更新服务，不改动现有本地库/离线文件格式。
