# 0.15.0 管理页与详情页改进

2026-10-19。以已验收的 0.14.0 为基础，对应用户提出的三项改进；本版本待安卓真机验收。

## 书架与下载管理

- 统一为 Material 3 封面列表，明确标题、作者、阅读进度、离线状态或下载进度；下载按作品分组，可展开查看章节和操作。
- 标题统计、来源切换、搜索、筛选和操作区随内容向上滚动。常规浏览只保留应用导航，选中内容后才出现底部批量操作栏。
- 书架将收藏夹切换、新建及删除集中到收藏夹面板；说明、最近阅读及离线文件入口收进更多菜单。
- 下载分组直接显示下载中、等待、暂停、失败和取消数量；保留章节任务暂停、继续、取消、重试、记录移除与本地库导入、导出、删除。
- 作品和章节使用 Sliver 延迟构建，避免整页一次构建所有列表项。

## 详情页集中下载

- 章节行用于进入阅读，不再摆放独立下载按钮。
- 顶部单一“下载”入口打开选章面板；默认勾选未下载且未排队的章节，支持搜索、全选当前筛选结果、仅选未下载和清空选择。
- 搜索条件变化会清空选择，确认按钮显示选中数量；关闭面板不创建任务。付费作品仍需先购买。
- 面板显示各章已下载、排队、下载、暂停及失败状态；确认后沿用原队列的去重、恢复和持久化逻辑。

## 详情页内评论

- 上方“章节 / 简介 / 评论”页签支持点击及左右滑动，无需另开评论页面。
- 封面和操作区向上收起后，只保留页签栏，为章节和评论腾出空间。
- 评论首次切到该页签时才请求，返回页签保留已加载内容与滚动位置。章节使用延迟构建，简介首次访问后构建。
- 评论支持滚动接近底部追加加载、手动加载、下拉刷新及失败重试；下一页失败不清空已有内容。保留发表、回复、草稿和登录入口，长回复列表可折叠。
- 账号“我的评论”复用同一评论模块，保留独立入口。
