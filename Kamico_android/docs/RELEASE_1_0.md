# kamico 1.0

版本 **1.0.0+27**，日期 2026-10-20。基线 0.23.0 已由用户真机验收。本版按 [确认计划](RELEASE_1_0_PLAN.md)实现，转入正式版版本序列。

## 用户行为

- 详情右侧信息块间距 24dp；JM 保留编号，Pic 隐藏编号。点赞为图标和粗体数字，缺失显示“—”，真实 0 显示 0；无障碍语义保留含义。
- 书架与本地历史“选择”按钮常驻、文案固定、再次点击关闭并清空勾选。共用浮动操作条的外围透明，列表尺寸不因显隐改变，按实际条高增加尾部滚动空间；下载库复用该布局。保留按源操作、撤销和就近完成入口。
- 外观新增发现入口排序页，拖动右侧手柄即时保存、支持恢复默认及无障碍上移/下移。两源共用顺序，Pic 略过连载和周刊。固定标识绑定名称/图标/路由，兼容缺失、重复和未知偏好。
- 阅读导航及底部控制层覆盖在漫画上，显隐和系统栏安全区变化不改动漫画布局；原阅读模式、控制器、页码、图片元素和进度保留。
- 关于页清理技术迁移介绍和更新占位说明。许可页合并相同 LGPL 文本，保留必要来源、MIT 和 GPL；默认收集器中仅供开发使用的依赖与应用重复条目在展示时过滤，共用正文中的运行组件和引擎条目继续保留。原许可正文和完整打包 NOTICES 保留。
- 初始化本地 Git，说明见 [REPOSITORY.md](REPOSITORY.md)，未配置远程地址或推送。

## 定位与检查

`verification-1.0.0-before.log` 记录修复前的 5 个失败场景：两页选择按钮、三种阅读模式菜单位移。`verification-1.0.0-layout.log` 记录修复后与既有阅读行为共 10 项通过。

根因：原阅读 AppBar 与底栏参与漫画布局；选择按钮被条件移除或变更文案；操作条作为 Column 底部区域挤占列表并露出外层底色。改为稳定内容区域和独立覆盖层。安全区显隐、图片边界和元素/控制器身份均纳入检查。

`release10_refinement_test.dart` 还覆盖实际手柄拖动、跨源/重新打开持久化、恢复默认、排序后的目标路由，以及许可范围保留。`ui23_refinement_test.dart` 继续覆盖点赞解析、数值缺失和跨源历史，按本版显示规则更新断言。

本机检查、合成预览与真实手机结论分别记录。继续使用既有依赖和缓存；账号写操作仅使用合成内容，不恢复已取消的专项帧性能任务。

最终静态检查无问题；全量 147 项通过、1 项可选预览跳过；专项及合成预览 20 项通过。对应日志见 [验证入口](VALIDATION.md)，合成预览保存于 `previews/1.0.0/`。
