# 0.23.0 历史与界面完善

版本 **0.23.0+26**，日期 2026-10-20。用户已确认前版 0.22.0 真机验收通过；本版按其四项反馈改进，原双源、账号隔离和离线兼容保持。

后续状态：用户已确认本版真机验收通过，并要求下一版转为正式版 1.0，先按 [1.0 计划](RELEASE_1_0_PLAN.md)进行设计。下方保留代理交付当时的检查记录。

## 行为与界面

1. 历史页始终保留“本地历史 / 云端历史”切换。缺失原因是旧实现用 `!session.isPic` 隐藏整组选项；先以 Pic 激活态的组件回归复现，再修复条件。两源本地记录按 JM / PIC 分组，复用书架封面卡片、两行标题、阅读进度及批量选择栏。保留搜索、分页、继续阅读、批量删除及撤销，源相同 ID 不冲突。
2. JM 云端历史使用原接口分页，未登录时引导登录；源、凭据或连接范围变化会清空旧结果，迟到的响应不能覆盖当前范围。Pic 原参考协议未提供云端历史接口，云端页说明限制并提供返回本地入口，不将本地数据伪装为云端。
3. 详情封面右侧增加点赞数。JM 读取 `likes`，Pic 详情读取 `totalLikes` 并兼容 `likesCount`；保留上游缩写或格式，实际 0 显示 0，缺失显示“点赞数暂无数据”。只读展示，不新增账号写入。
4. 阅读方向下拉与模式卡片同宽、默认 88dp 高和 24dp 圆角，图标/文字内边距对齐。模式卡片移除主题额外的上下 contentPadding；大字体可按内容增高，保持方向选择、屏幕常亮、模式和滑杆的原存储行为。
5. 切源按钮从账号卡移到“我的”标题右上角，发现页使用同款。48dp 圆形图标按钮，无小字，背景取 NavigationBar 的 indicatorColor。点击后停留当前页，两个账号仍独立；提示及无障碍语义携带当前源。
