# 当前状态与后续范围

更新日期：2026-10-20。当前正式版 **1.0.0+27**，已按授权完成本轮功能改动。实际交付与设备状态见 [RELEASE_1_0.md](RELEASE_1_0.md)，Git 状态见 [REPOSITORY.md](REPOSITORY.md)。0.23.0 是用户已验收基线。完整规则与接手入口见 [WORK_HANDOFF.md](WORK_HANDOFF.md)。

## 本轮完成范围（1.0）

- 正式版 1.0.0+27：清理开发/迁移介绍，精简关于信息与许可展示。
- 详情信息块增大间距，隐藏 Pic 编号，点赞改为图标和粗体数字。
- 书架/历史“选择”常驻且可重复点击开关，去掉圆角操作条外围矩形背景，保护列表尾部可见性。
- 外观增加发现入口拖动排序；两源共用顺序，Pic 略过 JM 专属入口，拖放后即时保存。
- 阅读菜单改为覆盖层，呼出/收起保持漫画画面和阅读位置稳定。

## 上版验收基线（0.23.0）

- 恢复两源下的本地/云端历史选项，历史列表复用书架的封面卡片、搜索和批量操作样式；本地仍按 JM / PIC 分区，JM 云端接口及分页保留，Pic 显示接口能力说明。
- 详情封面右侧显示点赞数；两源按各自上游字段解析，0 与缺失区分。
- 阅读方向下拉与阅读模式卡片的宽度、默认高度及圆角统一；原设置和持久化行为保留。
- 我的/发现页右上角使用同款圆形切源按钮，移除账号卡中的旧按钮和小字；当前页及独立账号状态保留。
- 双源、离线、PDF、账号和旧数据兼容沿用已验收的 [0.22.0 实现](MULTI_SOURCE_0_22.md)。本版检查见 [0.23.0 记录](UI_0_23.md)。
