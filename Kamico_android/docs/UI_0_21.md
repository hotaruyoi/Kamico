# kamico 0.21.0：筛选、选择与阅读设置

2026-10-20，基线为归档的 0.20.2+23，本版为 0.21.0+24。交付时用户无法连接 ADB，代理仅做本地验证与双版本打包，未执行安装或真机性能采样。

**最新状态：用户已确认本版真机验收通过，并明确取消本轮性能验证待办。下述未采样记录是交付时的证据边界，不再构成未完成任务。**

## 界面改动

- 新增共用 FilledSelect：无描边纯色填充、24dp 圆角，按钮显示字段和当前值；菜单相对按钮定位，显示完整文字与当前选项对勾，最多占屏幕高度 45%，长列表内部滚动。原固定 240dp 的下拉输入框已替换，包括外观设置。
- 周刊档期/连载星期与类型水平排列，宽度按 3:2 分配，长文字省略后可在菜单中读取完整内容。
- 分类、搜索的筛选和排序改为按钮下方的页面内面板；草稿与已应用条件隔离，应用才请求数据，取消不写入条件，重置草稿后仍需应用。窄屏单列、较宽屏两列选择器。
- 筛选面板随列表一起滚动。PagedComics 使用固定视口的 CustomScrollView 与 SliverGrid 懒构建，面板展开只改变内部内容高度，避免外置头部动画改变视口导致手势速率异常。
- 书架和下载共用的大圆角操作栏与两侧、底部保留间距，进入/退出多选时过渡；操作栏占用布局空间，最后一项不被遮挡。封面始终保留在左侧，复选框移到右侧，选择时复用封面 Element。历史与离线章节的复选框也移到右侧。
- 阅读设置改为固定标题/关闭按钮 + 内部滚动内容；分为常亮/方向、三种阅读模式、自动阅读/预加载，统一留白、填充选择器和圆角选项。最大高度为屏幕 88%，最大宽度 640dp。重复点击当前阅读模式不重建控制器；打开/关闭设置保持当前页码。
- 滑杆拖动只更新局部预览，松手后持久化，不再每个拖动事件写偏好及重建阅读页。

## 动效与兼容

公共按钮的状态过渡统一为 160ms；页面内展开为 240ms，弹层进入 240ms、退出 200ms。下拉菜单和更多操作菜单启用现有 Flutter Material 菜单动画，选择器箭头随展开状态旋转。全应用底部面板、确认/输入/评论等对话框使用共用过渡配置；开关、复选框、标签和分段按钮沿用 Material 内建反馈。普通工具图标默认透明。

自定义展开、旋转、模式切换和弹层遵循系统减少动画设置。没有为滚动卡片增加入场动画、循环动画或动态模糊，没有增加依赖或更新 SDK。数据格式、接口、三种阅读模式和旧数据迁移保持兼容。

## 0.20.2 对照及性能边界

从 `releases/0.20.2/source.zip` 核对：LocalStore、API 客户端、封面缓存分区、共享封面/背景图像以及原性能回归文件均与本版逐字节相同。封面解码尺寸、阅读进度不重建 MaterialApp、首页卡片不随滚动重建、封面缓存压力及详情到期后台刷新等原保护继续通过。

从归档提取 LocalStore 到 `build/ui-baseline-0.20.2/`，仅改相对导入以使用相同模型/依赖，采用 1500 条记录、100 次相同查询、5 次预热、10 次交替顺序采样。独立运行的本地中位数：基线 423μs、本版 332μs，样本区间分别为 265–641μs、254–414μs；见 [对照日志](baseline-comparison-0.21.0.log)。查询实现相同且采样有波动，不能将该差异解释为本轮带来的加速。已有独立查询基准也通过，见 [日志](benchmark-0.21.0.log)。

上述结果只证明本地行为及这些性能保护通过，不等于手机帧率数据。代理交付时未做真机 UI/栅格耗时、长帧比例、内存与 GPU 对照。随后用户真机验收通过，并取消本轮专项性能验证，因此不再安排这项对照；未来只有出现新的性能报告或相关任务时才重新按实际设备收集证据。
