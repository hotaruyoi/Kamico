# 发现页滑动速率跳变修复

日期：2026-10-19。针对 0.18.0 发现页头部收起后滑动忽快忽慢的报告。

用户已确认热重载修复效果，修复现已纳入 [0.18.1 双版本交付](RELEASE_0_18_1.md)。下文保留当时的复现与热重载证据。

## 原因与复现

旧实现用列表外的 `AnimatedSize` 收起头部，导致列表视口随动画不断变大，内容同时受到手指滚动和布局位移影响。

回归命令：

```powershell
flutter test --no-pub test/ui18_navigation_test.dart --plain-name 'discovery content follows a held drag'
```

修复前重复运行均失败：手指上移 40 逻辑像素后保持不动，内容锚点仍额外上移 136；滚动偏移保持 40，但视口高度从 708 变为 844。输出保留在 [复现日志](scroll-regression.log)。

USB 真机的 Dart VM 对象字段也显示相同模式：拖动前视口约 520.57，拖动时变为 740.57，另有约 220 逻辑像素的布局位移。手机存在继续阅读入口，头部高度不同于合成测试，不能直接比较两组绝对高度。

## 修复

搜索、快捷入口、继续阅读移入同一个固定视口的 `CustomScrollView`，使用 `SliverFloatingHeader` 随滚动收起和反向唤出。移除视口外的高度动画和手工方向监听；推荐网格继续按需构建，推荐 Future 保留。

## 验证与当前状态

- 原失败回归通过，补充正反方向持指时无额外位移、视口尺寸不变的断言。
- 静态检查无问题，完整 92 项回归通过，见 [检查日志](scroll-verification.log)。
- 手机从 Release 切换到同版本 Debug 后，热重载成功；没有截图，也没有向应用添加临时调试日志。
- 热重载后真机视口保持 740.57；相同拖动偏移为 91.43，手指不动继续观察仍为 91.43。数据经本机 Dart VM 对象字段读取，不代表 FPS 或 Release 性能基准。
- 当时仅更新工作区和调试会话；0.18.0 原始交付保持不变。确认后的修复在 0.18.1 构建中固化，不再依赖旧的热重载进程。
